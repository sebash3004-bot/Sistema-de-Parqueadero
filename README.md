# 🚗 Sistema Premium de Control de Parqueadero

Sistema integral para la gestión de entradas y salidas de vehículos con enfoque en seguridad y consistencia de datos.

## ✨ Características Principales
* **Scanner de Seguridad:** Verificación de vehículos en bases de datos de reportes de robo.
* **Protocolo Anti-robos:** Bloqueo automático ante detecciones sospechosas.
* **Cálculo Automatizado:** Tarifas basadas estrictamente en el tiempo de permanencia.
* **Persistencia Robusta:** Implementación de SQLite para garantizar la integridad ante fallos del sistema.
* **Interfaz Profesional:** Dashboard responsivo y limpio para operación en tiempo real.

## 🛠️ Tecnologías Utilizadas
* **Backend:** Node.js, Express.js
* **Base de Datos:** SQLite3
* **Seguridad:** Helmet.js, Dotenv
* **Frontend:** HTML5, CSS3 Moderno, JavaScript Vanilla

## 🚀 Instalación y Uso
1. Clona el repositorio: `git clone [TU_URL_AQUÍ]`
2. Instala las dependencias: `npm install`
3. Inicia el servidor: `node src/server.js`
4. Accede en tu navegador a: `http://localhost:3000`
